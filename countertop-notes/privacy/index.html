Privacy · current behavior and future gates

This static edition does not collect reader profiles.

No email address, cookie-based identifier, raw search query, or Amazon account information is collected by the public GitHub Pages build.

Site measurement

Events are disabled on the public Pages runtime

The repository includes a proposed five-event schema and a self-hosted Node endpoint. The request did not specify event names or fields; the static Pages artifact and default preview both serve a disabled runtime and send no analytics events.

Local preference

Suggestion selection stays in this browser

If you choose a path on the Suggestions page, that preference is stored in this browser's localStorage. It is not sent to the site or used to personalize other pages. You can clear it by removing the site's local storage in your browser.

Reader capture

No signup form is active

The site does not ask for or save email addresses. Reader capture will stay closed until a service, privacy/retention explanation, and functioning unsubscribe path are configured.

Future endpoint

Aggregate-only by design

If the self-hosted endpoint is deployed, the included server stores daily aggregate counts by event, page, and internal product record, with a 90-day default retention that the operator can configure. It does not persist IP addresses, cookies, full referrers, raw search queries, emails, or user IDs. The server uses a connection address transiently in memory for rate limiting; a hosting provider or reverse proxy may have separate request logs and retention. Production behavior must be tested and disclosed before measurement is described as active.

The current privacy state and implementation gate are recorded in Measurement and Flagged for Review. This page describes the current implementation, not a legal determination.
