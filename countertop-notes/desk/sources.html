Primary sources · checked 20 November 2026

Every sourced decision has a link you can open.

This register prefers official Amazon, FTC, Google, and GitHub pages. Product-page observations are labelled as observations only; they are not a substitute for Associates link tests or confirmation of owner intent.

Verification scope.

Public source pages were opened and reviewed. No authenticated Associates Central account, Search Console property, report export, product API, or mailing provider was accessed. Source IDs are local SRC-* labels; the request's S01/S02/S07/S24 mapping was not present in the repository.

SRC-01

Amazon Associates Program Operating Agreement

Amazon Associates Central · Page updated 2025-10-15. The agreement says Special Links must use the special tagged formats Amazon provides and requires the statement, ‘As an Amazon Associate I earn from qualifying purchases.’

SRC-02

Associates Program Policies

Amazon Associates Central · Page updated 2026-04-14. Program policies include Special Link formatting and PA API / Creators API content-use requirements. This is the primary policy source used for the link and automation gates.

Checked 2026-11-20
SRC-03

How do I build a simple text link to a specific item on Amazon?

Amazon Associates Central Help. Amazon documents a product link format that uses an ASIN and Associate ID, and recommends using its link-building tools. The submitted short-link path values are not copied into the intended-ASIN field.

Checked 2026-11-20
SRC-04

FTC's Endorsement Guides: What People Are Asking

Federal Trade Commission. FTC guidance says affiliate relationships should be disclosed clearly and conspicuously, close to recommendations and links; the guidance notes context matters and is not a safe harbor.

Checked 2026-11-20
SRC-05

How To use reports

Amazon Associates Central Help. Amazon Associates reports surface clicks, ordered items, shipped items and conversions, with reports selectable by Tracking ID. No account report was supplied or accessed for this project.

Checked 2026-11-20
SRC-06

How to read the Order Report

Amazon Associates Central Help. Amazon defines fields in the Order Report, including product-link clicks and product-link conversion. Project reporting fields remain blank until copied from an authorized first-party report with provenance.

Checked 2026-11-20
SRC-07

Are There Any Requirements to Use the Product Advertising API?

Amazon Associates Central Help. Amazon says PA API use requires an open Associates account, compliance with the Operating Agreement, and application for PA API subject to its license. No API credentials or account were supplied.

Checked 2026-11-20
SRC-08

Build and submit a sitemap

Google Search Central. Google documents sitemap formats, root placement, and sitemap submission options. The shipped sitemap lists the public publication pages and guides.

Checked 2026-11-20
SRC-09

Get started with Search Console

Google Search Central. Google describes verifying site ownership, checking indexing, submitting a sitemap if desired, and using Search performance reports for query and traffic data. Search Console ownership is not verified here.

Checked 2026-11-20
SRC-10

Using custom workflows with GitHub Pages

GitHub Docs. GitHub documents building and deploying static Pages artifacts with Actions. GitHub Pages does not run the Node analytics API included in this repository.

Checked 2026-11-20
SRC-11

CAN-SPAM Act: A Compliance Guide for Business

Federal Trade Commission. FTC guidance describes commercial-email requirements, including a clear opt-out explanation and a functioning opt-out process. No signup form or email collection is enabled.

Checked 2026-11-20
SRC-12

Can I Check If My Links Are Tagging to My Account?

Amazon Associates Central Help. Amazon describes checking the Store ID or Tracking ID in a generated link and says its Link Checker is for links created or modified outside Associates Central. The supplied links have not been tested in an enrolled Associates workflow.
