FLG-001Open — confirmation required

Product intent is not confirmed for any submitted link

Finding: All five intended ASIN, intended official listing URL, confirmation date, and confirmation source fields are blank. The observed redirect target is kept in a separate field and is not used to populate intent.

Irregularity / limit: The submitted path tails are each nine characters. Amazon's link-building help describes an ASIN separately from the Associate ID; these tails are therefore not recorded as intended ASINs. This observation does not establish that any submitted link is invalid.

Next discovery step: Match every submitted link to the owner's intended item and record the official listing, intended ASIN, date, and evidence before publishing a product recommendation.

FLG-007Open — backend hosting required

Real site analytics are not active on GitHub Pages

Finding: The repository includes a self-hosted aggregate-count Node endpoint and a five-event schema proposal. The static Pages artifact and default preview config both disable event sending; the preview API rejects events unless explicitly enabled in an isolated local environment.

Irregularity / limit: No cross-visitor click or conversion data is collected by the default preview or live static site. The campaign ledger remains empty.

Next discovery step: Only after event-schema approval, deploy the API on a separately reviewed host or same-origin reverse proxy; test privacy controls and event counts before using data to optimize content.
