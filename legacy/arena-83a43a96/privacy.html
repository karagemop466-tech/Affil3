Privacy

No cookies, no personal data

This site does not set cookies, does not track individuals across sites, and does not collect names, emails, addresses, or payment information. There are no user accounts.

Click measurement

Outbound clicks on links marked rel="sponsored" are counted by a privacy-preserving client-side script. For each click it records only:

  • event type (outbound_click)
  • target URL (destination of the link clicked)
  • link text (first 120 characters)
  • whether the link carried rel="sponsored"
  • the page the click happened on
  • an opaque session identifier stored in localStorage
  • a timestamp

No IP addresses, fingerprints, or personally identifiable information are included in the event payload.

Where events go

Events are queued in localStorage and sent to a self-hosted analytics endpoint at /analytics/collect via a fire-and-forget beacon (sendBeacon / fetch keepalive). If the endpoint cannot be reached, events remain queued locally and are retried.

Status: The /analytics/collect endpoint is not self-hosted on GitHub Pages (static hosting). The frontend instrumentation is in place; a separate self-hosted receiver must be deployed before click measurement is operational. See FLG-004.
