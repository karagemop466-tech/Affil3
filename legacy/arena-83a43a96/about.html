About Affil3

Brand and voice

Affil3 is a buyer-led affiliate publication: buyer questions come first, verified links come second. Guides are written around questions a buyer would actually ask. No copy is presented as "trending," "best-selling," or "top-rated" unless it can be traced to a source.

Authorship

This site was built in a single autonomous session (session ID arena-83a43a96-affil3, branch arena/83a43a96-affil3) against a requirements set for an Amazon affiliate publication with tracking ID shopnow047c-20 (unverified — see FLG-001). There is no human editorial staff yet; every page states its editorial status plainly.

Verification standard

  • Every data value in site tables is either linked to an official source or left blank.
  • No value is inferred or filled in. A blank field means "not confirmed," not "unknown but probably X."
  • The five submitted Amazon short links (link.amazon/...) could not be dereferenced in this environment (outbound access to Amazon is unavailable). They are kept exactly as submitted, marked rel="sponsored", and not claimed invalid. Their compliance status is unresolved — see FLG-003.

Search Console and real analytics

Google Search Console has not yet been enabled for this property; enabling it requires a Google account and owner verification (steps below). Until then, topic selection cannot be driven by measured queries — a gated item, not a claim of performance.

Steps to complete (site owner action required)

  1. Verify the property in Google Search Console (search.google.com/search-console).
  2. Submit sitemap.xml in Search Console so Google has one site to index.
  3. Deploy the self-hosted endpoint at /analytics/collect so the five defined events flow to first-party reports.
  4. Add timestamps, source, channel, eligible sessions, clicks, and reported orders to the campaign ledger only when obtained from authorized first-party reports, with a dated provenance trail (Priority 4).

Compliance gate

  • Every outbound product link carries rel="sponsored".
