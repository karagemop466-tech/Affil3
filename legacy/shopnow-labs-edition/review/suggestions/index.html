Rebuild outbound links as tagged Special Links before driving any traffic

The observed redirects from the five submitted short links carried no Associates tag. A click through them cannot be attributed to this account. Until the tagged form is confirmed to track, publishing more content sends traffic into a hole.

Zero effort, but no evidence they attribute to this tag.

Cleanest source of truth for the exact required format, but needs an enrolled account.

Turn on real measurement before writing another word

Choosing the next guide from instinct is the most expensive habit available. But this build can only ship the instrument, not the readings: an analytics endpoint needs a host and a privacy decision, and Search Console needs domain verification.

A Self-hosted, cookieless endpoint on a subdomain you control
No consent banner needed for aggregate, non-identifying counts; requires a host and DNS record.
B Google Analytics 4
Free and capable, but adds a third-party script and a consent obligation in several jurisdictions.
C ✓ Ship the event calls now, endpoint later
Events fire into a documented queue with no collector; no data is lost from the code's perspective, but nothing is recorded yet.
Evidence: C-05, C-18
Desk recommendation: path A
Cannot proceed yet: Needs a host and a privacy decision from the owner. Logged as FLG-006.

Lead with the products, keep the checking in the footer

The first version of a compliance-heavy affiliate site usually opens with its verification process, which is the least interesting thing to a buyer. The front page should look like a publication front page: a lead story, a product grid, a clear next step. The register, the claims and the flags stay reachable but stop being the headline.

A ✓ Publication front page, registers in footer
Buyer-friendly, but a reviewer has to scroll to find the audit trail.
B Dashboard front page with all tables
Great for the operator, poor for a reader, and reads exactly like the 'audit' the brief says to avoid.
No regulatory evidence required: this is an editorial judgement.
Applied as: index.html rebuilt as a front page: lead guide, product grid, collections, then a single footer group linking every dashboard surface.

Do not publish prices

Amazon permits price display only when Amazon serves the link or when the figure comes from the Creators API or PA API. This site has no API credentials, and scraped prices drift within hours. Publishing them would be both a policy risk and a guaranteed inaccuracy.

A ✓ No prices; link to the live listing
Slightly less convenient for the reader, fully defensible, and never wrong.
B Scrape and display prices with a 'last updated' note
Violates the price-display condition in the Program Policies and will be stale.
C Apply for Creators API access, then display API-sourced prices
The correct long-term path, but requires approved API credentials that we do not have.
Evidence: C-09, C-10, C-26
Applied as: No price appears on any page. Every product links to the live listing instead.

SUG-08 applied in this build Trustworthy machinery high impact

Keep intended and observed link destinations in separate fields

The submitted short links do not carry the tag in the redirect we observed. Recording 'what we meant' and 'what we saw' in one field is how a broken affiliate link goes unnoticed for months. Separating them makes the mismatch auditable and lets a validator fail on it.

A ✓ Two fields, validator requires them to agree before publish
More data entry; the only way to detect drift automatically.
B Single 'link' field
Cheap now, invisible failures later.
Evidence: C-02, C-19
Applied as: data/products.json: intended_asin / intended_listing_url vs observed_redirect_target / observed_tag_parameter.

SUG-07 applied in this build Trustworthy machinery high impact

Put a hard gate in front of publishing

Automation should handle the mechanical checks and refuse to publish when a human-only judgement is needed. A link that resolves to a different ASIN than intended, a missing disclosure, or a product with no verified identity should fail the build rather than go live.

A ✓ Deterministic validator runs in CI and blocks the build
Occasionally blocks on a false positive, which is the correct failure direction for compliance.
B Checklist a human follows before publishing
No enforcement, and the check silently stops happening under deadline.
Evidence: C-02, C-03, C-05
Applied as: tools/validate.mjs, wired into .github/workflows/checks.yml; a failing gate prevents deploy.

SUG-06 blocked by policy Trustworthy machinery high impact

Do not use AI to write the guides from Amazon listing text

The brief asks for an AI-powered content engine. The Program Policies prohibit using Program Content or Special Links to develop machine learning models without prior written approval. So the automation boundary is: a model may draft from our own notes and public non-Amazon sources, but Amazon listing text must not be piped into a model to generate articles.

A ✓ Human-written guides, automated checks
Slower to scale; compliant; this is what was built.
B Model-generated articles from scraped listing content
Likely breach of the ML-use clause, and produces the exact generic tone the brief rejects.
Evidence: C-24
Cannot proceed yet: Requires prior written approval from Amazon for Program Content use in model development. Not available to this project.

SUG-02 applied in this build Findable high impact

Publish question-shaped guides instead of category pages

A category page competes with Amazon. A question does not. Each of the six guides answers one question a buyer actually types, then hands off to the product that fits the answer. This is the cheapest organic-traffic strategy available to a site with no domain authority.

A ✓ Six question guides, one per decision
Needs ongoing cadence to compound; six pages is a start, not a strategy.
B One long 'best air fryer' listicle
Highest competition, most likely to be ignored, and impossible to keep accurate as prices move.
No regulatory evidence required: this is an editorial judgement.
Applied as: content/guides/*.md — six guides, each with its own URL, canonical, sitemap entry and feed item.
What would change our mind: Search Console query data showing these questions get no impressions and a different question set does. That requires the site to be verified in Search Console first (see SUG-11).

Hold the guide cadence to what can be verified

A publishing calendar only compounds if every entry is true when it ships. A cadence of two verified guides a month beats eight unverified ones, and the gate can enforce the difference.

A Two guides per month, each gated
Slower growth, higher survival rate.
B Weekly programmatic pages
Volume without verification produces exactly the site this brief rejects.
Evidence: C-15, C-16

The brief asks for both a simple table of entries and a findings table. Those are different documents with different readers. Merging them produces a table nobody can use for either purpose.

B One table containing both
Every buyer row inherits audit jargon and every audit row inherits marketing tone.
No regulatory evidence required: this is an editorial judgement.

Use text and typography instead of Amazon product photography

Program Content may only be used as licensed, and image caching is restricted. Republishing listing photos is the single most common way affiliate sites breach the IP License. A monogram-and-typography treatment keeps the page looking designed without borrowing anyone's assets.

A ✓ Typographic product cards, no third-party imagery
Less visually rich than a photo grid; zero licensing risk; no third-party requests on load.
B Hotlink listing images
Risk under the IP License and breaks whenever the URL rotates.
C Commission original photography
Best result for trust and SEO, but it is a real cost and cannot be produced from this environment.
Evidence: C-11, C-12
Applied as: Monogram tiles generated from the brand name; zero external asset requests.

A ✓ Plain 'tell me when a guide publishes' capture, no reward
Lower signup rate than an incentive; compliant.
B 'Subscribe for a 10% off code'
Prohibited incentive structure when tied to Special Links.
Evidence: C-23
Applied as: Capture block on the front page and guide index, wired to a local placeholder handler that records nothing until an endpoint exists.

SUG-14 applied in this build Read like a publication medium impact

State authorship, ownership and correction policy up front

Readers forgive limits that are declared and distrust claims that are implied. Naming the desk, saying it has not physically tested the products, and publishing a correction policy costs almost nothing and is the difference between 'a review site' and 'a content farm'.

A ✓ Editorial standards page plus a byline on every guide
Admits the desk has not tested the products, which is honest and also a differentiator when most competitors hide it.
B Anonymous site with implied authority
Reads like generated content, which is the failure mode the brief names.
Evidence: C-15, C-16
Applied as: /editorial-standards/, byline block on every guide, /review/sources/.

Add a seasonal spine and named collections

A publication has a calendar. Seasonal groupings give an editor a reason to publish on a schedule and give a reader a reason to return, without inventing urgency or fake deadlines.

A ✓ Named collections tied to cooking occasions
Needs refreshing each season or it reads stale.
B Countdown timers and 'deal ends tonight' banners
Manufactured urgency on prices we cannot verify. Avoid.
Evidence: C-16
