How to decide

  1. Filter by priority: the four high items are the ones the brief's own logic demands first (measurement, gate G3, intent record, cadence).
  2. Pick an option per suggestion (the recommendation is a default, not a verdict).
  3. Record the decision via the link in the last column (opens a pre-filled GitHub issue) or in the repository's COORDINATION.md board.
  4. Only then does implementation start — and it lands with its own verification rows.
