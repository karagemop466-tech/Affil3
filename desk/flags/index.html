Flagged for review

Items this desk could not settle from an official source. None of them block the site going live. Each one has the source that was checked, what is missing, and the exact step that would close it.

Nothing on this page is a claim about a product. Everything here is a statement about our own verification, and every one of them links to the official page that was read.

FLG-001 high severity needs review

The tracking ID shopnow047c-20 could not be confirmed as issued

What was checked
Amazon publishes the shape of an Associates tag: an Associates ID or "tag" (appearing as XXXXX-##, or such other format as we may designate). The submitted value shopnow047c-20 matches that shape.
What is missing
No public Amazon page confirms that the tag shopnow047c-20 was issued to this account, that it is active, or that it is the store ID that the site's Special Links should carry.
Impact
If the tag is wrong, clicks still reach Amazon but the sale may not be attributed, and every Special Link on the site needs to change.
How to close it
Open Associates Central, copy the Store ID from the account header, and paste it into data/config.json as affiliate.tracking_id. Re-run the build.
Source
https://affiliate-program.amazon.com/help/operating/policies
FLG-002 high severity needs review

The intended ASIN for each submitted link is unconfirmed

What was checked
Amazon defines an ASIN as a 10-character alphanumeric unique identifier. Three of the five submitted tokens are 9 characters, so they cannot be ASINs. Two are 10 characters but neither was confirmed as an issued ASIN.
What is missing
Nothing in the public record binds a short link token to a specific product, so the intent behind each link cannot be read from any public source.
Impact
The register can state where each link goes today. It cannot state what was meant. Both facts are kept in separate fields and neither is merged into the other.
How to close it
The owner confirms the intended ASIN and listing URL for each of the five links. Until then the intended fields stay blank by design.
Source
https://affiliate-program.amazon.com/creatorsapi/docs/en-us/api-reference/operations/get-items
FLG-003 high severity needs review

The submitted short links are not the format this site publishes

What was checked
Amazon's Program Policies require that Special Links be accessed directly from your Site, restrict Redirecting Links and restrict link shorteners that make it unclear that you are linking to an Amazon Site.
What is missing
Nothing is missing in the rules; the point is that the five submitted link.amazon URLs are Amazon-hosted redirects rather than direct Special Links carrying the Associates tag. Whether each short link is enrolled in the owner's Associates workflow is a private fact that cannot be read from a public page, so no compliance verdict is stated here.
Impact
If the short links are not already enrolled, replacing them with direct Special Links is what makes the click attributable.
How to close it
Open one submitted link in the enrolled Associates workflow, confirm the destination and the tracking report, then publish direct Special Links for the rest. Do not scale until one link has been confirmed end to end.
Source
https://affiliate-program.amazon.com/help/operating/policies
FLG-004 medium severity needs review

Two submitted tokens are ASIN-shaped but were not confirmed live

What was checked
B0c8moW59 and B0f3GKalj are each 10 characters, which matches Amazon's ASIN definition. A direct fetch of www.amazon.com/dp/B0c8moW59 and www.amazon.com/dp/B0f3GKalj did not return a retrievable product listing on 2026-11-20. The link quoted here is the confirmed destination of the B0c8moW59 submission, so it is the evidence for the observation rather than for the token itself.
What is missing
Whether these two tokens are issued ASINs that point at a different product, or are simply unused codes.
Impact
If a token is itself a live ASIN, the submitted link and the intended product may be two different things, which would change the editorial plan.
How to close it
Run a Creators API GetItems call with itemIds set to the two tokens and itemIdType ASIN, and read what comes back.
Source
https://www.amazon.com/dp/B0DHZTCNR5 Sponsored
FLG-005 medium severity needs review

The Associates account behind this site is not publicly verifiable

What was checked
The GitHub Pages configuration for this repository is public. The Associates enrolment that would let a reader confirm the site's own account is not.
What is missing
Public evidence that the site operator holds an active Associates account and which store ID it uses.
Impact
Enrolment, approved Site URLs and payment details all sit behind a login.
How to close it
Add the live site URL to the approved Site list in Associates Central once the domain is settled.
Source
https://affiliate-program.amazon.com/help/operating/agreement
FLG-006 medium severity needs review

Commission rates for these two categories were not verified

What was checked
Amazon states that Standard Commission Income is described in the Appendix of the Program Policies, and that the rate card and payment charts sit behind sign-in.
What is missing
The actual percentage for Kitchen and Dining products and for Kitchen Utensils and Gadgets products.
Impact
No revenue estimate, ranking or 'highest commission' claim appears anywhere on this site, because none of that could be verified.
How to close it
Read the rate card in the Program Policies Appendix while signed in, and record it in data/products.json with the date it was read.
Source
https://affiliate-program.amazon.com/help/operating/policies
FLG-007 medium severity needs review

Creators API access needs 10 qualifying sales in the past 30 days

What was checked
Amazon lists the prerequisites for Creators API access, including at least 10 qualifying sales within the past 30 days.
What is missing
An API-enabled account, so the live price and availability lookup cannot be exercised yet.
Impact
The price and rating widgets on this site stay blank and link out to Amazon instead of showing a figure.
How to close it
Register for Creators API in Associates Central, then set the API credentials in the server environment rather than in the repository.
Source
https://affiliate-program.amazon.com/creatorsapi/docs/en-us/introduction
FLG-008 low severity needs review

PA-API 5 no longer works

What was checked
Amazon's deprecation notice states that PA-API 5 has been deprecated and that calls now receive an HTTP 403 with an AccessDeniedException.
What is missing
Nothing. This is a confirmed change, not an open question.
Impact
Any research tooling built against PA-API 5 endpoints would fail silently or loudly. The tooling in this repository targets the Creators API instead.
How to close it
Already handled. Kept here because it is the single most likely thing to trip up inherited code.
Source
https://affiliate-program.amazon.com/creatorsapi/docs/en-us/paapiv5-deprecation
FLG-009 medium severity needs review

No measured search data yet, so no topic ranking is claimed

What was checked
Nothing to check yet. The site has been live for less than a day and no search console or analytics property is connected.
What is missing
Real query data, impressions, click-through rates and the outbound click and reader capture events this site records.
Impact
The publishing plan lists candidate guide topics as hypotheses. None of them is described as popular, high-volume or trending.
How to close it
Verify the site in Google Search Console, connect the analytics endpoint, publish for a season, then pick the next topic from the measured queries rather than from instinct.
Source
https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links
FLG-010 low severity needs review

Listing contents drift over time

What was checked
Amazon's own policies state that prices and availability change, and the Operating Agreement states that the service offerings are provided as is and may change at any time.
What is missing
A way to pin the exact text of a listing permanently.
Impact
Every title and spec on this site is a snapshot with a date attached, not a live feed.
How to close it
The register already carries an observed_on date on every row. A scheduled refresh through the Creators API would keep it current.
Source
https://affiliate-program.amazon.com/help/operating/agreement
FLG-011 low severity needs review

A near-identical ThermoMaven listing exists under a different ASIN

What was checked
On the B0DHZTCNR5 listing page read 2026-11-20, Amazon's own 'Customers who viewed this item also viewed' module showed B0GL7Z4KP4 with the title 'ThermoMaven 1 Sec Professional Digital Meat Thermometer, ±0.5℉ Accuracy | NIST&NSF Certified, Auto-Rotate Bright LED Screen, IP67 Waterproof for Grill BBQ, Stocking Stuffers Gifts for Men, Orange'.
What is missing
Which of the two ASINs is the listing the owner wants promoted, and whether they are colour variants of one product or separate listings.
Impact
Publishing the wrong variant sends readers to a page with different options than the one described.
How to close it
Check both ASINs in a Creators API GetItems call and confirm the intended colour and variant before publishing a product page for that slot.
Source
https://www.amazon.com/dp/B0DHZTCNR5 Sponsored
FLG-012 low severity needs review

GitHub Pages logs visitor IP addresses

What was checked
GitHub's documentation states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes regardless of consent.
What is missing
Nothing. This is a published platform behaviour and is recorded so the privacy note is accurate.
Impact
The site's own analytics never collects an IP address, but the hosting platform does. The privacy note says so rather than claiming the site is IP-free.
How to close it
Already disclosed on the site. Listed here so the review is complete.
Source
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
