The data we can and cannot publish

Amazon's rules decide what may appear on a page at all. Getting this wrong is what gets an account closed.

ID Priority Question What we already know What is missing How to close it Status
Q-06 P1 May this site display a price, and if so, how does it get one?
Blocks: Whether price and availability can be shown on product pages
Program Policies 2(b) allows prices and availability on your Site only if Amazon serves the link that displays them, or if you obtain pricing through Creators API or PA API. The GetItems reference exposes prices only through the offersV2.listings.price resource. Live API credentials, so no price can be fetched yet. Register for Creators API and wire the price lookup to the self-hosted endpoint. Until then the widget stays blank and links out.
Source: affiliate-program.amazon.com
open
Q-07 P2 May this site show Amazon star ratings or customer review counts?
Blocks: Whether ratings and review counts can appear in comparison tables
Program Policies 5(t) bars displaying Amazon customer reviews or star ratings on your Site unless they are obtained through Creators API or PA API. They were seen while reading the listing pages, and they are deliberately absent from every table on this site. API access, which would make a rating display compliant. Same as Q-06. Until then the comparison tables compare only what the official titles state.
Source: affiliate-program.amazon.com
open
Q-08 P2 Which API should the platform call, and what happens if it is called with old credentials?
Blocks: How the research tooling talks to Amazon
PA-API 5 is deprecated. Calls to it now return HTTP 403 with an AccessDeniedException. The Creators API is the supported path, with the host https://creatorsapi.amazon, a regional token endpoint and the scope creatorsapi::default. Client credentials for the Creators API. Register in Associates Central and set the credentials in the server environment, never in the repository.
Source: affiliate-program.amazon.com
open
Q-09 P3 Which specifications can be repeated on this site without an API call?
Blocks: Which product attributes are safe to restate
Program Policies 2(b) forbids inaccurate, overbroad or misleading claims about any Product, and separately restricts prices and availability. The safe reading is that descriptive attributes taken from the official listing title can be restated as long as they stay accurate. A published Amazon ruling on exactly which attribute classes are restricted. The line drawn on this site is conservative. Review the first season of published copy with the account owner's compliance reviewer.
Source: affiliate-program.amazon.com
open
Q-10 P2 Does a comparison page need extra original content to host Special Links?
Blocks: Whether the comparison pages are allowed to exist as product lists
Program Policies 2(b) says that when linking to pages with Product lists you must have additional original content on your Site that is relevant to the Special Link, and defines product lists to include search results, events and department homepages. Nothing. Each comparison page on this site carries original written analysis alongside the links. Already handled. Listed so the review can confirm the analysis is genuinely original and not a rewritten manufacturer blurb.
Source: affiliate-program.amazon.com

Trust, disclosure and site machinery

The site has to read like a publication and still survive a compliance review.

ID Priority Question What we already know What is missing How to close it Status
Q-16 P1 Does the disclosure clear both Amazon's standard and the FTC's guidance on placement?
Blocks: Whether the disclosure strip is prominent enough
Amazon requires the statement to be clearly and prominently stated where Program Content appears. The FTC says disclosures are likely to be missed if they appear only on an About page, at the end of a post, or behind a click. This site puts the statement directly under the masthead on every page and repeats it in the footer. A human compliance read of the final rendered pages. Open the live site on a phone and confirm the strip is above the fold and legible at every width.
Source: www.ftc.gov
open
Q-17 P1 Is every outbound product link marked as sponsored and pointing directly at Amazon?
Blocks: Whether outbound links are correctly marked
Google's documentation states that paid placements should be marked with rel="sponsored", and that multiple rel values may be combined. Amazon requires that Special Links carry the Associates tag and be accessed directly from your Site. Nothing for the build. The build gate fails if a product link lacks the sponsored rel or a direct amazon.com destination. Already automated in the check step. Listed so the review knows the gate exists and can be re-run.
Source: developers.google.com
closed
Q-18 P2 Does the click counter collect anything it should not?
Blocks: Whether the analytics collector is legally usable
The collector stores no IP address, no user agent, no cookie, no advertising identifier and no email address. It uses a rotating per-visitor pseudonymous id, honours Do Not Track, and sends nothing when no endpoint is configured. GitHub Pages separately logs visitor IP addresses for security, which the privacy note states. A jurisdiction-specific privacy assessment, which depends on where the audience is. Have the privacy note reviewed against the audience's location before scaling up traffic.
Source: docs.github.com
open
Q-19 P3 Who is the byline on a page, and does it need to be a person?
Blocks: Whether the site needs a formal authorship policy
The Operating Agreement requires original content with significant commentary, analysis or transformation of any third-party material. Amazon's own Endorsement Guides note that a disclosure must come from the endorser, not from someone else. A decision about whether the desk is presented as a named editorial team or a single named reviewer. Pick a byline model in the Suggestions section before the first season of publishing.
Source: affiliate-program.amazon.com
open
