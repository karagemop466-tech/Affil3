Privacy

This site sets no cookies, loads no webfont, makes no request to any third party, and — as of this build — stores nothing at all about you. The measured state and the code are described on the metrics page.

If collection is ever switched on

  • Only the five events named in the schema may be recorded.
  • No IP address is stored. No cookie or fingerprint identifies a reader. Page paths are stored; query strings are dropped, so a tagged link cannot leak a session value into a log.
  • Do Not Track and Global Privacy Control signals stop collection before the first event, in code rather than in prose.
  • Checklist ticks live in your own browser's storage and never reach us.

Reader details

The email field on guide pages does not send anything, because no capture endpoint is configured. It says so on the page rather than quietly swallowing what you typed. If that changes, this page changes in the same commit — and the build fails if collection is enabled while the privacy text still promises nothing.

Amazon

Following a link here takes you to Amazon, where their own cookie and privacy terms apply, including the attribution window that lets a purchase you make later still credit the link you clicked. We keep no record of that and cannot see its contents.
