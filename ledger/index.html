Empty. No authorized first-party report has been imported, so there is nothing to report.

A row is added only from an authorized first-party report, for example an Associates report exported by the account owner. Every row carries the date it was imported, the period it covers, the report it came from, and the file or URL kept with it. Nothing is estimated, scraped or modelled. No conversion score or revenue forecast is presented anywhere on this site.
