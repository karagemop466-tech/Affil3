Trustworthy machinery · gates before automation

Automate the checks. Keep a human at the publication gate.

The repository contains an evidence workflow, not an active AI product researcher. Account access, authorized data, and an editor's sign-off are prerequisites—not assumptions.

Automation is not connected.

No Amazon API credentials, Associates report, model provider, or data license were supplied. There is no product discovery score, trend detector, price watcher, review analyzer, commission forecast, or automatic publishing in this build.

01 · Authorize

Confirm Associates account, website, Tracking ID, API eligibility, and permitted data use.

02 · Source

Fetch only permitted data; retain its source, timestamp, and refresh instructions.

03 · Draft

Use AI only for a cited draft if rights and policy allow; do not invent missing fields or use restricted Program Content for model training.

04 · Approve

A human verifies product intent, disclosure, claims, link destination, and required policy checks before publication.
