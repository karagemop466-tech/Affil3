Privacy

Privacy notice

Plain-English version; the technical details live on the measurement page.

What we collect today

Nothing. No cookies are set by this site, no analytics runs, no data leaves your browser. The measurement script is present but inert: it sends nothing until an analytics endpoint is configured (FLG-009), and it checks your browser's Do Not Track setting before it would ever send anything.

If measurement is turned on later

Only five events would be recorded (page views, category views, product views, outbound clicks, and a 75%-read signal on guides), aggregated per day. No cookies, no IP addresses, no user agents, no fingerprinting, no account data, nothing you type. The project rule: if analytics is enabled, this page is updated first, and the change is recorded in the repository history.

Affiliate links

Product buttons link to Amazon with our Associates tracking ID (a tag parameter in the URL). Amazon's own systems handle anything that happens after you leave this site; their use of that click is governed by Amazon's privacy practices, not by this notice. We never route clicks through a redirect, and we never see which reader clicked what.

Questions or requests

Open an issue in the project repository. Corrections are logged on the Flagged for review page.
