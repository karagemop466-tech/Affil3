Privacy

What this site records about you

Short version: right now, nothing. The measurement script is on every page but it has no destination configured, so it returns before sending anything. This page describes what would happen if that changed, because you are entitled to know before it does.

What loads on every page

One script, assets/analytics.js, and one stylesheet. There is no advertising script, no social widget, no third-party tag and no cookie banner, because there are no cookies to banner about. You can read the script: it is in the repository at src/assets/analytics.js, and the build gate fails if it ever sets document.cookie, localStorage or sessionStorage.

What it does today

The script looks for a destination address in a <meta name="analytics-endpoint"> tag. That tag is empty on every page of this site, and the script's second line is an early return when it is. Nothing is sent anywhere. This is a deliberate default rather than an oversight: the collector has no host and no owner yet, and measurement without someone responsible for the data is how a small site ends up holding personal data it should not have.

What it would send if the endpoint were switched on

Five events, and only those five — the name list is duplicated in the browser script, in tools/collector.mjs and in data/events.json, and the build gate fails if the three disagree:

EventWhen it firesWhat is sent
page_viewOnce per page load.path, referrer_host
category_viewOnce per category page load.category
product_viewWhen a product row or card is shown on a page (once per page load).product_id
outbound_clickWhen a reader clicks a product link. The link itself is not redirected; the browser goes straight to the Amazon URL.product_id, destination_host, placement
guide_read_75When a reader scrolls past 75% of a guide.guide

The collector stores daily aggregate counts. It does not store rows per visitor, and there is no way to reconstruct a session from what it keeps.

What is never collected

  • cookies
  • IP address
  • user-agent
  • account data
  • anything typed into the page
  • a returning-visitor identifier of any kind — there is no ID to have, because nothing is stored on your device
  • anything from a browser that sends Do Not Track; the script returns early and counts nothing

Links to Amazon

Product links are not redirected and not proxied. When you click one, the script records the click and your browser goes directly to the Amazon URL — the two happen independently, and the link works whether or not the measurement does. Those links carry our Associates tracking ID, which is how Amazon attributes a purchase to this site, and they are marked rel="sponsored".

Once you are on amazon.com, Amazon's own privacy notice governs what happens next, not this page — it is at amazon.com/gp/help/customer/display.html?nodeId=468496, reachable from the footer of any Amazon page. Amazon sets its own cookies there. That is true of any affiliate link on any site, and it is the reason affiliate disclosure exists.

That reference is deliberately plain text and not a link. The build gate marks every amazon.com hyperlink on this site as rel="sponsored", which is correct for the product links that pay for this site and would be a misstatement for a citation to Amazon's own help pages. Google's guidance reserves sponsored for advertisements and paid placements. Rather than mislabel the link or weaken the gate, the URL is given as text. Refining that rule is recorded as an open decision (S-25) rather than being changed here.

Why we disclose this at all

Amazon's Associates Program Policies, Participation Requirements 3(e), make the Associate responsible for disclosing on the Site "the use of cookies, pixels, and other technologies by you and third parties and how you collect, use, store, and disclose data collected from visitors". We currently use none of those technologies, and this page exists so that the statement is on the record before the endpoint is switched on rather than after.

If a third-party analytics product were adopted instead

That is an open decision, not a plan. If it were taken, a separate processor would appear, this page would be rewritten to name it and describe what it collects, and the choice would be recorded in the decision log on the Suggestions page. Nothing on this site currently sends data to any third party.
