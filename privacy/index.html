Privacy

What this site records about you

Short version: right now, nothing. The measurement script is on every page but it has no destination configured, so it returns before sending anything. This page describes what would change if that were switched on, because you are entitled to know before it happens rather than after.

What loads on every page

One stylesheet and one script, both from this site. There is no advertising script, no social widget, no third-party tag and no cookie banner, because there are no cookies to banner about. The build gate fails if any page loads a stylesheet, script or webfont from another origin, so that property is enforced rather than promised.

You can read the script. It is in the repository at src/assets/analytics.js, and the gate fails if it ever sets document.cookie, localStorage or sessionStorage.

What it does today

The script looks for a destination address in a <meta name="analytics-endpoint"> tag. That tag is empty on every page of this site, and the script returns immediately when it is. Nothing is sent anywhere. That is a deliberate default rather than an oversight: the collector has no host and no owner yet, and measuring without someone responsible for the data is how a small site ends up holding personal information it should not have.

What it would send if the endpoint were switched on

Five events, and only those five. The name list is duplicated in the browser script, in the collector and in data/events.json, and the build gate fails if the three disagree, so a sixth event cannot be added quietly.

EventWhen it firesWhat is sent
page_viewOnce per page load.path, referrer_host
category_viewOnce per category page load.category
product_viewWhen a product page or product card is shown, once per page load.product_id
outbound_clickWhen a reader clicks a buy link. The link is not redirected; the browser goes straight to the Amazon URL.product_id, destination_host, placement
guide_read_75When a reader scrolls past 75 percent of a guide.guide

No cookies. No IP address stored. No user-agent stored. No fingerprinting. No cross-site identifiers. Counts are aggregated per day, and browsers sending Do Not Track are not counted at all.

What is never collected

  • cookies
  • IP address
  • user-agent
  • account data
  • anything typed into the page
  • cross-site identifiers
  • a returning-visitor identifier of any kind — there is no ID to have, because nothing is written to your device
  • anything at all from a browser that sends Do Not Track; the script returns early and counts nothing

Links to Amazon

Product links are not redirected and not proxied. When you click one, the script records the click and your browser goes directly to the Amazon listing — the two happen independently, and the link works whether or not the measurement does. Those links carry our Associates tracking ID, which is how Amazon attributes a purchase to this site, and they are marked rel="sponsored".

Once you are on amazon.com, Amazon's own privacy notice governs what happens next, not this page. It is reachable from the footer of any Amazon page, under "Privacy Notice". Amazon sets its own cookies there. That is true of every affiliate link on every site, and it is a large part of why affiliate disclosure exists.

That reference is deliberately plain text and not a link. This site's link policy adds the tracking tag and rel="sponsored" to every retail amazon.com link, which is right for a product link and would be a misstatement for a citation to Amazon's own help pages — Google reserves sponsored for advertisements and paid placements. Rather than mislabel the link or weaken the policy, the reference is given as text. Amazon's documentation hosts are already exempted by the policy; its help pages on www.amazon.com are not, and refining that is recorded as an open decision (S-18) rather than changed here.

Photography

Photography on this site is editorial illustration, not the reviewed units. No product image on this site is Amazon Program Content, so no question arises about altering or redistributing Program Content through it.

If a third-party analytics product were adopted instead

That is an open decision, not a plan. If it were taken, a separate processor would appear, this page would be rewritten to name it and describe what it collects, and the choice would be recorded in the decision log on the suggestions page. Nothing on this site currently sends data to any third party.
