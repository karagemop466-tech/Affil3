How to read this table

  • Intended ASIN — taken from the link path. It is what the owner intended, not a confirmed listing.
  • Observed redirect target — the URL reached by following the link on 2026-11-20, from a non-browser fetch. It may differ for a signed-in visitor.
  • ASIN check — MISMATCH means both ASINs exist and differ. UNRESOLVED means no product was reached.
  • tag= — whether the tracking ID shopnow047c-20 appears in the observed target. None does.
