Five defined events

Names carried over from the prior measurement plan. Definitions to be confirmed (FLG-012).

EventFires whenPayloadStatus
page_viewEach page load (once per load).event name, page path (no query string), empty product id.Not receiving: no endpoint configured
disclosure_impressionWhen the disclosure strip under the masthead is at least half visible.event name, page path.Not receiving: no endpoint configured
product_impressionWhen a product card is at least half visible (once per card per page).event name, page path, product id (P01…P05).Not receiving: no endpoint configured
guide_viewEach guide page load.event name, page path.Not receiving: no endpoint configured
outbound_clickA click on any link marked rel="sponsored" (product CTAs).event name, page path, product id.Not receiving: no endpoint configured

Setup: the receiver in analytics/collect_server.py is tested locally. It is not hosted, and GitHub Pages cannot run it (FLG-004, SUG-02).

Privacy rules for measurement

  • No cookies and no localStorage or sessionStorage writes.
  • No user identifiers, IP addresses or user agents stored by the receiver.
  • Do Not Track and Global Privacy Control are honoured: nothing is sent.
  • Only the five event names above are accepted; anything else is rejected.
