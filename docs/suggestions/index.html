Suggestions review

This is the review surface: proposed improvements with options, impact, effort, and the gate that must pass before implementation. Nothing here is implemented without a chosen path. Use the Questions register for the missing information that decisions depend on.

How to choose

The review flow

1. Read the gate

If the gate condition isn't met (e.g. analytics not live), the suggestion stays pending until it is.

2. Pick an option

Each suggestion lists options A/B/C with a recommendation. Choose one per suggestion, or defer.

3. Record the decision

Update the status in data/suggestions.json — accepted, declined, or deferred — and commit.

4. Implement only after

Implementation happens in a separate commit after the decision, so review and build stay separate.
