SG-28 awaiting choice (shipped in d state) effort m needs Q-18, Q-19

Click and conversion measurement on a static host

Count the click, not the person.

Parallel pass row from the brief, and the hardest one here: Pages serves no backend, so there is nowhere to write an event. Third-party analytics is the usual answer and it is the answer that makes privacy pages necessary.

Proposal

Ships in two halves. (1) docs/assets/track.js: intercepts commerce-link clicks, no cookies, no IP capture, no fingerprinting, per-tab session token in sessionStorage, bounded local buffer, and a POST to an endpoint only when one is configured. (2) scripts/collect.mjs: a 90-line stdlib Node endpoint that appends NDJSON and serves a totals view. Wire them with one env var. Five events are defined in register/measurement.json and nothing is invented if an event never fires.
