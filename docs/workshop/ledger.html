The Workshop · Campaign ledger & analytics

Measurement, gated honestly

Priority 4 — measure before automating optimization. This campaign ledger starts empty but well-defined. Rows are added ONLY from authorized first-party reports: Amazon Associates reports for reported orders (and their own session/click figures), or the self-hosted analytics endpoint for eligible sessions and clicks once deployed. Each row carries a dated provenance entry. No conversion score or revenue forecast is presented anywhere in this project.

The gate: self-hosted endpoint

  1. Deploy tools/analytics-endpoint/ (Cloudflare Worker reference, or the Python stdlib server) on the host chosen in SUG-004.
  2. Set analyticsEndpoint in docs/site-config.js — that single line releases the counter.
  3. The endpoint stores only {event, path, ts, ref} — no cookies, no IP, no user agent, no cross-site identifiers.
  4. Rows appear in the ledger only from authorized first-party reports, each with a dated provenance entry. Until then: no sessions, no clicks, no orders, no forecasts.
