One-link test protocol

  1. In Associates Central open Links > Special Links and generate a product link for the P01 ASIN with tracking ID shopnow047c-20.
  2. Compare that generated URL against candidate_url above. If they differ, the generated one wins and becomes the template - record the difference here.
  3. Open a clean incognito window, paste the link, and confirm the listing shown is the intended ASIN.
  4. Add an item to the basket (do not purchase). Return to Associates Central > Reports > Transactions and confirm a session or click appears with the tracking ID.
  5. Record date, browser, outcome in test_log below. Only then mark validated and scale to P02-P05.
  6. If step 4 shows nothing, the failure is in attribution, not in the page - stop and re-check the site registration (Q-07) before publishing more links.

Do not conclude: Do not record the supplied link.amazon short links as invalid. Their compliance status is unresolved (FLG-003); this session observed no tag on the final URL, which is not the same as proof that no attribution was carried.

Campaign ledger

0 rows by design
timestamp_utcsourcechannelperiod_startperiod_endeligible_sessionsclicksreported_ordersreported_unitsearnings_amountcurrencyprovenancecaveats
Empty. Rows may be added only from an authorised first-party report, each with its own date and provenance. No derived, backfilled or modelled figure is ever entered here.

Integrity rules

  • A row may not be created by arithmetic on other rows. Derived metrics (CTR, EPC, conversion rate) are computed at read time from recorded numerators and denominators, and are hidden when the denominator is below a stated floor.
  • No row may be backfilled with an estimate for a period the source did not report.
  • Every row carries its own source and date; the file is append-only so the trail stays dated.
  • If a figure later changes (returns, cancellations), a new row is added and the old row is annotated, not edited.

Read-time floors before any ratio is shown

  • outbound_click_through_rate — clicks / eligible_sessions, shown only when eligible_sessions >= 100
  • click_to_order_rate — reported_orders / clicks, shown only when clicks >= 50
  • earnings_per_click — earnings_amount / clicks, shown only when clicks >= 50
  • why_floors_exist — At pilot volume a single order moves a ratio by tens of points. A floor is the difference between a metric and a mood.

Explicitly not instrumented

  • scroll depth and dwell time - noisy, low decision value, high creep factor
  • mouse movement or any fingerprinting input
  • per-user persistent identity across visits
  • third-party pixels of any kind, including ad-network tags
  • recording what the reader typed into on-site search (the zero-result count is aggregated instead)

Collector contract

  • endpoint — POST /event, application/json, one event object
  • response — 204 on accept, 400 on unknown event id
  • storage — append-only NDJSON at data/events.ndjson
  • totals — GET /summary returns per-event counts per day
  • configured_by — window.SHOPNOW_COLLECTOR (string URL) injected by the builder only when register/site.json carries a collector_url
  • run_locally — node scripts/collect.mjs --port 8788
