Discovery suggestions for the things nobody can answer yet

  • Read the redirect yourself. Open each supplied link in a normal browser and copy the final URL. Five minutes, closes Q-01 and usually Q-02.
  • One screenshot per account screen. Tracking IDs, Site Settings, the API access control, and Reports > Transactions answer six questions at once and give the register dated provenance.
  • Verify Search Console the day the domain exists. It costs nothing and its value is strictly a function of how early the clock starts.
  • Ask the cheapest reader question first. Zero-result queries on the search page are a free demand signal the moment traffic exists — no tool, no cost, no consent problem.
  • Write down the number you would quit at. Q-20 has no source and needs one: a stopping rule is data about you, and it is as recordable as any metric.
