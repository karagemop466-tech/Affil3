This is a pre-check, not a link generator. The real Special Link must be produced inside Associates Central, its destination confirmed, and a test click seen in reports (gate G5) — then the link and its confirmation go into data/products.json, and every page's CTA updates from that one file.

Kill switch

If G5 fails or attribution can't be confirmed, flip require_verified_links to true in data/products.json and redeploy: every outbound CTA site-wide renders as a disabled "Listing verification pending" button. One file, one flag, whole-site effect.
