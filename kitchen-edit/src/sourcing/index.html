How this shapes the site

Disclosure placement

[S04] + [S07] → the reader-support strip sits under the masthead on every page (above the fold), the required statement repeats in every footer, and each CTA is labeled "(paid link)". CI fails any page that drops them.

Link discipline

[S01]/[S03] → public CTAs are marked rel="sponsored", driven from one config file, and carry a kill switch. Status flips to "verified" only after the in-account test (gate G5).

Blank-until-sourced

[S05] → the ASIN format check that shaped the intent records. No price, rating or spec appears anywhere because nothing was confirmed from a listing's own offer data. Blanks stay blanks.
