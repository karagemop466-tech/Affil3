Questions before decisions

The clear list of questions that must be answered before any decision can reasonably be made — what information we already have, what we don't, and how to discover the missing parts. Machine-readable: data/questions.json.

Q-01 · Are the five submitted short links Associates-generated Special Links carrying shopnow047c-20? P0

We know
  • All five live under the .amazon gTLD operated by Amazon Registry Services [S09].
  • Observation 2026-11-20: four resolved to amazon.com product pages; none carried tag=shopnow047c-20 [FLG-003].
  • Commission pays only on clicks through Special Links [S01, S03].
Missing
  • Whether each link was generated inside Associates Central and whether clicks attribute to the ID.
How to discover
  • Associates Central → Reports → Links: click one and check attribution · regenerate one link per product via SiteStripe/Link Builder · compare destination and tracking.
Blocks
  • Verified CTA status; any conversion measurement we can trust.

Q-03 · Which exact products do the five links intend? Do observed landings match? P0

We know
  • Submitted path identifiers are 9 chars; official ASIN definition is 10 [S05].
  • Observed landing ASINs differ from path identifiers in every observed case (B04G1MEwY→B0CDY277D3, B02NbDxp3→B09B7SB46R, B00hJ57DV→B08DKYBTPH, B0f3GKalj→B0DZFD6R9Z, B0c8moW59→unresolved).
  • Intent and observation are kept separate, never merged.
How to discover
  • Ask the submitter for original product URLs / SiteStripe screenshots · one GetItems call per ASIN once Creators API is active [S13].
Blocks
  • Verified profile fields; comparison table; any "best for" claims about specific products.
