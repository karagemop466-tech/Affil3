Suggestion review board

This section exists so someone can review suggestions and choose the best path before implementing any changes. Each card states what changes, the evidence behind it, the realistic options, and the decision needed. Statuses: proposed under review implemented. Machine-readable: data/suggestions.json.

SG-08 · DECISION — analytics endpoint hosting proposed

What
Choose where events POST to. A. Serverless worker + KV (self-hosted code, ~free) · B. Self-hosted analytics app on a small VPS (full control, ~5 USD a month + ops) · C. Local queue + manual exports (zero infra, no live measurement).
Evidence
FLG-002: static hosting can't run the endpoint [S10]; the brief requires a self-hosted endpoint.
Impact / effort / risk
High impact · effort B > A > C · risk: A/B add a privacy contact point; C delays conversion measurement indefinitely.
Decision needed
Pick A, B, or C; then set analyticsEndpoint and record the choice here.
