How the queue works

  1. A link is submitted — its intended identifier and URL are recorded exactly as given, with the date and source.
  2. The link is followed once — the destination is recorded in a separate observed field. If Amazon’s checkpoint page appears, the field stays blank and a flag opens.
  3. The listing is quoted verbatim — titles and category paths, each with its source link. Manufacturer wording is labeled as such; it is not our test result.
  4. Nothing scales before validation — one link per product must pass the Associates workflow test (destination + tracking report) before any link counts as final.
