The Workshop · Open questions

What we don’t know yet — and how to find out

The honest list. Each entry separates what we already know from what is missing, names the way to discover it, and says which decision waits on it. Nothing on this list is guessed.

Q-001

What products do the five submitted link tokens intend to identify?

partially answered FLG-001 FLG-004
What we already know
The five submitted URLs and their tokens (S-14). Four submitted links resolved on 2026-11-20 to observed Amazon listings (P-01/02/03/05); those observed targets are recorded separately from the intended tokens and are not merged with them.
What is missing
An authoritative statement of what each token is meant to be (the tokens themselves do not match Amazon's documented 10-character ASIN format — FLG-001).
How to discover it
Open each submitted link in the enrolled Associates account/browser session and record the destination; or have the owner confirm each intended product.
What it blocks
Any statement that the site 'is about' five specific products; product-spec claims; scaling to more links.
Q-002

Do the submitted short links — and the provisional tagged URLs on the site — satisfy the Associates Special Links requirements?

open FLG-003 FLG-005
What we already know
The Operating Agreement requires links to use the special 'tagged' link formats Amazon provides (S-01). The brief says the short links' exact compliance status is unresolved and must not be called invalid (FLG-003).
What is missing
Result of the one-link-per-product test in the enrolled Associates workflow (destination + tracking report).
How to discover it
Associates Central → SiteStripe/Link Checker on one link per product; check the Orders report after test clicks.
What it blocks
Bulk link replacement, adding more products, any compliance sign-off.
Q-003

What are 'the five defined events' the brief asks the analytics endpoint to record?

open FLG-006
What we already know
The brief says 'record the five defined events' but never enumerates them. The campaign-ledger row fields the brief does enumerate are timestamp, source, channel, eligible sessions, clicks, reported orders (data/ledger.json).
What is missing
The authoritative five-event list.
How to discover it
Owner supplies the list, or accepts the proposed schema (SUG-003: page_view, outbound_click, guide_read, newsletter_signup, feedback_click).
What it blocks
Freezing the analytics event schema; dashboard design.
Q-004

Which host will run the self-hosted analytics endpoint?

open FLG-006
What we already know
GitHub Pages cannot run server-side code (FLG-006). Reference implementations ship in tools/analytics-endpoint/ (Cloudflare Worker; Python stdlib server).
What is missing
Owner's hosting choice and budget.
How to discover it
Owner decision from SUG-004 options.
What it blocks
Turning on the click counter (currently dry-run).
Q-005

Which reader-capture (newsletter) mechanism should the site use?

open FLG-008
What we already know
Capture UI ships and is wired to site-config.js captureEndpoint; it collects nothing while the endpoint is null (FLG-008).
What is missing
Provider decision (self-hosted Listmonk, Buttondown, MailerLite, etc.) and account.
How to discover it
Owner decision from SUG-005 options.
What it blocks
Live email collection; first dispatch cadence.
Q-006

What is the Google Search Console verification token for the site property?

open FLG-007
What we already know
Sitemap, robots.txt, canonical URLs, and feed are ready (SG-28 done; SG-29 gated).
What is missing
Verification token/file from the owner's Google account.
How to discover it
Owner creates the property and drops the token into the reserved slot (workshop page has steps).
What it blocks
Search Console query data — which the brief wants to drive topic selection.
Q-007

Is the Associates account for tag shopnow047c-20 enrolled and in good standing?

open FLG-003 FLG-005
What we already know
The tracking ID is supplied in the brief (S-14). US-format tags end in '-20', consistent with shopnow047c-20.
What is missing
Confirmation of enrollment status, and access to Associates reports/SiteStripe.
How to discover it
Owner signs in to Associates Central; record status here.
What it blocks
FLG-003/FLG-005 link tests; first-party order data for the campaign ledger (Priority 4: authorized first-party reports only).
Q-008

What do spec codes S01, S02, S07, S24 and SG-27..SG-30 define in the source specification?

open FLG-009
What we already know
The brief's own wording maps SG-27..SG-30 to nav labels, RSS feed, Search Console, reader capture; S02 appears against Special Links validation; S01/S07/S24 appear against disclosure/Operating Agreement/FTC review.
What is missing
The source specification document these codes come from.
How to discover it
Owner supplies the spec, or confirms the provisional mapping (this register + FLG-009).
What it blocks
Treating any of those rows as fully specified requirements.
Q-009

What publishing cadence can the owner review and sustain?

open
What we already know
The brief requires a publishing cadence and measured topic selection. A proposal of two question-shaped guides per month plus seasonal anchors is on the decision queue (SUG-002).
What is missing
Owner's available review time and any hard deadlines (e.g. holiday season windows).
How to discover it
Owner decision.
What it blocks
Committing the editorial calendar on the About page.
Q-010

Should the site display prices or ratings at all?

open FLG-010
What we already know
Per verification rules, unconfirmed volatile values stay blank (FLG-010). The site currently shows none and says 'Check today's price'.
What is missing
Decision on a compliant price/rating source (e.g. Product Advertising API) or continued omission.
How to discover it
Owner decision from SUG-006.
What it blocks
Any price display feature.
Q-011

Is the site brand 'The Crisp Index' approved?

open
What we already know
A brand is needed for the publication front page; 'The Crisp Index' is a session proposal (SUG-001), used provisionally so the site could ship.
What is missing
Owner approval or a replacement name.
How to discover it
Owner decision.
What it blocks
Nothing structural (name is a template constant), but masthead/marketing copy depends on it.
Q-012

What counts as a 'reported order' for the campaign ledger and any optimization?

open
What we already know
The brief says the ledger takes reported orders only from authorized first-party reports (Amazon Associates reports), and that no conversion score or revenue forecast is presented (Priority 4).
What is missing
Whether to count shipped orders, dispatched items, or returned-adjusted totals; which attribution window.
How to discover it
Owner decision aligned with Associates report semantics.
What it blocks
Ledger population; any later optimization automation.
